# REYES EPK Website

A responsive, single-page REYES electronic press kit.

## Deploy with GitHub + Vercel
1. Create a GitHub repository (for example `reyes-epk`).
2. Upload `index.html` and the complete `assets` folder to the repository root.
3. In Vercel, import the repository.
4. Framework preset: **Other**. Build command: leave blank. Output directory: `.`.
5. Deploy.

The two SoundCloud players are embedded in the Music section. The exact section heading is **ORIGINALS / REMIXES**.

Replace the Instagram link in `index.html` with the artist's direct profile URL if desired. The current source EPK image did not expose a reliable profile URL.
